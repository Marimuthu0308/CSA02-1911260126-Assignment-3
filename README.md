4. TASK DESCRIPTIONS
==================================================

TASK 1 – LIBRARY CATALOGUE SEARCH

This program searches for a library accession number using binary search.

Concepts used:
- Arrays
- Functions
- Binary Search
- Comparison counting

The program displays the position of the searched accession number and the number of comparisons performed.

TASK 2 – SORTING ALGORITHMS

This program sorts a list of integers using three sorting algorithms.

Algorithms:
- Bubble Sort
- Selection Sort
- Insertion Sort

The sorted output of each algorithm is displayed for comparison.

TASK 3 – MERGING MERIT LISTS

This program merges two descending merit lists into a single descending list.

Concepts used:
- Arrays
- Merging
- Two-pointer technique

The merged list maintains descending order.

TASK 4 – DISTRICT RAINFALL ANALYSIS

This program processes rainfall data for 38 districts over 12 months.

The program calculates:
- Annual rainfall for each district
- Monthly average rainfall
- Wettest district and month
- State average annual rainfall
- Districts receiving less than 60% of the state average

Sample rainfall values are generated inside the program, so manual input is not required.

TASK 5 – STRING PROCESSING

This program performs string operations without using the string length function.

Operations:
- Count the number of words
- Check whether a string is a palindrome
- Ignore letter case while checking palindromes
- Handle punctuation and whitespace

TASK 6 – NAME DIRECTORY

This program manages a list of names.

Operations:
- Sort names alphabetically
- Search for a name using binary search
- Identify duplicate names

Sample names and the search name are provided inside the program.

TASK 7 – ELECTION VOTE COUNTING

This program counts votes for multiple candidates.

Operations:
- Count votes for each candidate
- Identify valid and invalid votes
- Display candidate vote totals
- Identify the winner
- Detect a tie between candidates

Sample votes are predefined inside the program.
